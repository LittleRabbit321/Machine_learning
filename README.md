# PEMS04 生成式交通流量时空预测

机器学习课程第一次作业。项目使用 PEMS04 数据集，以过去 12 个时间步的交通状态预测未来 12 个时间步、全部 307 个传感器的交通流量。

核心模型采用 **图时空条件变分自编码器（GCN-GRU-CVAE）**：图卷积提取道路空间关系，GRU 提取时间依赖，条件 VAE 学习未来交通流量的概率分布并完成多步生成预测。

## 1. 作业目标

- 输入：过去 12 个时间步的流量、占有率和速度；
- 输出：未来 12 个时间步、307 个节点的交通流量；
- 数据划分：按时间顺序划分训练集、验证集和测试集，比例为 6:2:2；
- 数据处理：使用训练集统计量进行 Z-Score 标准化；
- 生成式方法：条件 VAE，不使用传统简单监督回归作为最终模型；
- 测试指标：在反归一化后的原始尺度上计算 MAE、RMSE 和 MAPE；
- 截止日期：2026 年 11 月 18 日。

## 2. 数据说明

原始数据包包含：

| 文件 | 说明 |
|---|---|
| `PEMS04.npz` | 交通状态数据，预期形状为 `(16992, 307, 3)` |
| `adj_mx.pkl` | 307 个传感器之间的邻接矩阵 |
| `PEMS04.csv` | 传感器或道路节点辅助信息 |
| `data_check.py` | 数据查看示例 |
| `adj_data_check.py` | 邻接矩阵查看示例 |

三维特征依次为流量、占有率和速度。原始数据放在 `data/raw/PEMS_04.data/`，该目录已被 Git 忽略，不上传到远程仓库。组员应从课程共享位置单独获取数据，并保持相同目录结构。

## 3. 统一数据接口

所有模块统一使用以下张量格式：

```python
x.shape = (batch_size, 12, 307, 3)
y.shape = (batch_size, 12, 307, 1)
adj.shape = (307, 307)
```

- `x`：过去 12 步的流量、占有率和速度；
- `y`：未来 12 步的流量；
- `adj`：处理后的邻接矩阵；
- 所有张量统一使用 `torch.float32`；
- 均值和标准差只能由训练集计算，禁止使用验证集或测试集统计量。

数据模块必须提供：

```python
train_loader, val_loader, test_loader, scaler, adj = load_data(config)
```

模型训练接口必须提供：

```python
prediction, loss_dict = model(x, y, adj)
```

模型推理接口必须提供：

```python
prediction = model.generate(x, adj, num_samples=1)
```

预测输出形状必须为：

```python
prediction.shape = (batch_size, 12, 307, 1)
```

### 成员2：时间序列样本构造

负责文件：`src/data/dataset.py`

主要任务：

- 检查 `PEMS04.npz` 的形状、特征和缺失值；
- 按时间顺序完成 6:2:2 数据划分；
- 使用滑动窗口构造过去 12 步到未来 12 步的样本；
- 防止训练集、验证集和测试集之间发生时间泄漏；
- 编写数据形状测试。

报告内容：数据集介绍、数据划分、滑动窗口和样本构造。

验收结果：能够输出划分正确的 `x`、`y` 数据集，形状符合统一接口。

### 成员3：预处理与图结构

负责文件：`src/data/preprocessing.py`

主要任务：

- 仅使用训练集计算 Z-Score 的均值和标准差；
- 实现标准化与反标准化；
- 读取 `adj_mx.pkl`，检查邻接矩阵形状；
- 完成自环添加和邻接矩阵归一化；
- 构建 PyTorch `DataLoader`。

报告内容：Z-Score、邻接矩阵处理、数据统计和数据加载流程。

验收结果：实现统一的 `load_data(config)` 接口，并验证反标准化能够还原数据。

### 成员4：图时空特征提取器

负责文件：`src/models/backbone.py`

主要任务：

- 实现图卷积，提取传感器之间的空间依赖；
- 实现 GRU 或 TCN，提取 12 步历史序列的时间依赖；
- 将空间和时间模块组合成条件特征提取器；
- 使用模拟数据测试输入输出维度。

报告内容：图卷积原理、时间建模方法、时空编码器结构与公式。

验收结果：输入 `(B, 12, 307, 3)`，输出约定维度的历史条件特征。

### 成员5：条件 VAE 生成模型

负责文件：

- `src/models/cvae.py`
- `src/models/losses.py`

主要任务：

- 实现条件编码器和潜变量分布；
- 输出 `mu` 和 `logvar`；
- 实现重参数采样；
- 将历史条件和潜变量输入解码器；
- 生成未来 12 步流量；
- 实现预测损失、KL 散度和 KL 权重退火；
- 支持多次随机采样，展示预测不确定性。

报告内容：条件 VAE、重参数技巧、生成过程和损失函数。

验收结果：训练和推理接口符合统一约定，输出形状为 `(B, 12, 307, 1)`。

### 成员6：训练与超参数实验

负责文件：

- `src/training/trainer.py`
- `src/training/early_stopping.py`

主要任务：

- 实现训练和验证循环；
- 使用 Adam 优化器；
- 实现学习率调度、早停和最佳模型保存；
- 比较学习率、批次大小、隐藏维度、潜变量维度和 KL 权重；
- 保存每次实验的配置和训练日志；
- 只使用验证集选择模型，不使用测试集调参。

报告内容：实验环境、训练流程、超参数设置、调参过程和早停策略。

验收结果：提交最佳权重、配置文件、训练日志和超参数对比表。

### 成员7：评估、消融与可视化

负责文件：

- `src/evaluation/metrics.py`
- `src/evaluation/visualization.py`

主要任务：

- 在反标准化后计算 MAE、RMSE 和 MAPE；
- 计算未来第 1 至第 12 步的分步指标；
- 绘制真实值与预测值曲线、空间误差热力图和训练曲线；
- 展示多次生成的均值与不确定性区间；
- 完成无图卷积、无 KL 损失等消融实验结果整理；
- 说明 MAPE 对接近零流量的处理方式。

报告内容：评价指标、测试结果、消融实验、可视化和结果讨论。

验收结果：提交测试指标表和可以直接用于报告的全部图表。

长期分支：

- `main`：只保存最终稳定版本；
- `develop`：各模块的日常集成版本。

个人任务分支建议：

```text

```

协作流程：

1. 从最新的 `develop` 创建自己的任务分支；
2. 只修改自己负责的核心文件；
3. 完成本地测试和对应报告章节；
4. 向 `develop` 提交 Pull Request；
5. 至少由一名搭档检查后再合并；
6. 最终版本由成员1从 `develop` 合并到 `main`。

交叉检查关系：

- 成员2与成员3互查数据模块；
- 成员4与成员5互查模型模块；
- 成员6与成员7互查训练和评估模块；

